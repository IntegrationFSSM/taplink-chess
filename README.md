## ✨ Fonctionnalités

- 📱 **Mobile-First & Ultra Responsive** : Conçu spécifiquement pour une utilisation sur smartphone, tablette et écran d'ordinateur.
- 🎨 **Design Moderne & Thème Échecs** : Effets de *Glassmorphism*, touches or et vert échecs, animations fluides au survol.
- ⚡ **100% Statique & Léger** : Aucun framework lourd ou build step requis. Pure HTML5, CSS3 et JavaScript vanilla.
- 📋 **Bouton Copie Rapide** : Permet de copier l'adresse email en un clic avec notification toast.
- 🌐 **Partage & QR Code** : Support de l'API native `navigator.share` et générateur de QR Code intégré pour afficher le Taplink sur le campus.

## 🚀 Déploiement GitHub Pages

Pour activer ce Taplink directement et gratuitement via GitHub Pages :
1. Rendez-vous sur votre dépôt GitHub : `https://github.com/IntegrationFSSM/taplink-chess`
2. Cliquez sur **Settings** > **Pages** (dans le menu de gauche).
3. Sous **Branch**, sélectionnez `main` et le dossier `/(root)`.
4. Cliquez sur **Save**.
5. Votre site sera instantanément en ligne à l'adresse :
   👉 **`https://integrationfssm.github.io/taplink-chess/`**
